# 🌍 Portfolio de Azeez Ridwan

## 📖 Introduction

### Contexte  
Azeez Ridwan est un développeur full-stack et créatif digital. Ce projet de portfolio a pour objectif de mettre en avant :  
- Ses compétences en développement web (Django, FastAPI, React, Next.js, MySQL).  
- Sa spécialisation en **création de visuels hyperréalistes et vidéos publicitaires avec IA**.  
- Ses services en community management et accompagnement digital.  

### Objectifs  
- Présenter son profil et ses compétences.  
- Exposer des projets passés (web, dashboards, publicités IA).  
- Attirer des prospects (freelance, remote, clients locaux et internationaux).  
- Permettre un **contact direct** (formulaire, email, réseaux sociaux).  

### Public cible  
- Clients potentiels (PME, agences, ONG, startups, indépendants).  
- Recruteurs et partenaires techniques.  
- Public général intéressé par ses créations visuelles.  

---

## 🎯 Description générale du projet

Le projet est un **site portfolio dynamique** avec :  
- Une partie publique (présentation, services, projets, contact).  
- Une partie back-office (administration via Django admin).  

---

## ⚙️ Fonctionnalités

### Partie publique  
- **Accueil** : présentation rapide, photo, accroche.  
- **À propos** : biographie professionnelle, compétences techniques et créatives.  
- **Services** : développement web, création visuelle IA, community management.  
- **Portfolio / Réalisations** :  
  - Liste de projets (vignettes + détails).  
  - Catégorisation (Web, IA, Vidéo, Community Management).  
  - Pages détaillées par projet (description, images/vidéos, techno utilisée).  
- **Blog / Actualités (optionnel)** : articles, astuces et nouveautés.  
- **Contact** : formulaire de contact (Nom, Email, Message) + intégration réseaux sociaux.  

### Partie back-office (Django admin)  
- Gestion des projets (CRUD).  
- Gestion des articles (CRUD si blog activé).  
- Gestion des services.  
- Gestion des messages reçus via le formulaire.  

---

## 🏗️ Architecture technique

- **Backend** : Django (Python 3.12+)  
- **Frontend** : Django templates + HTMX  
- **Design** : TailwindCSS, responsive  
- **Base de données** : MySQL ou PostgreSQL  
- **Serveur** : VPS (Hostinger ou équivalent)  
- **Serveur applicatif** : Gunicorn / Uvicorn  
- **Proxy web** : Nginx  
- **Sécurité** : Certificat SSL (HTTPS via Let’s Encrypt)
